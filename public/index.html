            About Predator Watch

            Predator Watch is a free, open-source map. It brings together predator data that government agencies already publish, starting with gray wolves, and refreshes each source as often as the agency updates it.

            Every item shows which agency published it, when the agency observed or last updated it, and when this map received it. Each layer has a freshness badge. Data is shown at the same precision the agency publishes, never finer.

            Only public agency data is used here. A private collaboration space for ranchers, community members, and agencies is Planned.

            Source code and the full list of data sources: github.com/steelhead99x/predator-watch-app (Apache-2.0).
