About Predator Watch

Predator Watch is a free, open-source map of predator data that government agencies already publish. Today that means gray wolves, with bear ranges as an optional layer group. Agencies post this data in many formats on many sites. This map puts the public sources in one place and shows, on every item, who published it and how old it is.

Methodology

  • Public agency sources only. Each source is a dataset that a wildlife or land agency publishes for anyone to use. Sources are added only after their terms of use are checked. The data sources list gives the URL, license and terms for each one.
  • No added precision. Geometry is shown as the agency publishes it. Some agencies generalize locations into cells, pack areas or management units; the map never makes them finer. A shaded area is where the agency reports activity, not where an animal is now.
  • One format. Each source is converted into the same GeoJSON shape, with the agency name, the agency's own observed or edited date, the date this map received it, the license and a link back to the original.
  • Change tracking. When a source changes, the map records how many items were added, changed or removed, so you can see what moved between updates.
  • No private data. There is no rancher data, user location tracking or user-submitted sightings in the public map. A private collaboration space is planned and would be separate from this map.

Data freshness

A scheduled job runs every 15 minutes. Each source has its own refresh interval, from 15 minutes for weather alerts to weekly for management boundaries that rarely change. The job asks the agency whether anything changed and only downloads data when it did. Visitors never cause a request to an agency; they are served from a cache.

Each layer shows badges:

  • Agency updated …: the date the agency says it last edited the data. Some services do not publish one, and the badge says so.
  • Checked …: when this map last asked the agency.
  • Refresh failing or Refresh overdue: the last checks did not succeed, or none has run on schedule. The map keeps showing the last good copy.

The status page lists every source's last success, error and item count.

Limitations

  • Coverage is only as complete as what agencies publish. No layer means no public agency data has been added for that area yet, not that no animals are there.
  • Agencies publish on their own schedules. Some layers are annual or older. Read the agency's notes, linked from each layer's “About this source”, before relying on it.
  • Collar-based data covers collared animals only.
  • Management units and hunt areas are regulatory boundaries, not activity.
  • This map is not an emergency or safety service. Contact the agency directly for anything urgent.

Report an error or suggest a source

  • Wrong or out-of-date data, or something broken: open a bug report. Include the layer name and a link to the view (the address bar keeps it).
  • A public agency dataset we should add: suggest a source.
  • Errors in the data itself are best reported to the agency that published it as well; each layer links to its source.
  • Security issues: see SECURITY.md.
